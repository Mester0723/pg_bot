# 🐍 Pokemon Telegram Bot

Telegram-бот для игры с покемонами: создавайте, кормите, развивайте и сражайтесь с другими покемонами.

## Возможности

- Создание и развитие покемона
- Кормление с таймером
- Сражения между покемонами
- Достижения и уровни

## Команды

- `/go` — создать покемона
- `/feed` — покормить
- `/attack` — атаковать (ответом на сообщение)
- `/achievements` — достижения
- `/level` — уровень и опыт

## Пример

```
/go
/feed
/attack
```

## Важно

- Не публикуйте токен Telegram!
